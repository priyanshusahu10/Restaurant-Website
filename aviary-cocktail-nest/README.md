# Aviary Cocktail Nest — Premium Restaurant Website

## Run locally
1. Keep the folder structure unchanged.
2. Open `index.html` directly in a browser, or use VS Code Live Server.
3. All supplied restaurant photos are in `assets/`.

## Included
- Premium responsive landing page
- Sticky-style transparent header over hero
- Mobile navigation
- Menu category tabs
- Reservation modal
- Gallery lightbox
- Review slider
- Call and Google Maps direction links
- Responsive layout for desktop/tablet/mobile

## Important
The reservation form is a front-end demo. To make it actually send bookings, connect the submit handler in `script.js` to your backend, WhatsApp, email service, or reservation API.
